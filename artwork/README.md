# Archived original artwork

Source artwork kept for provenance and regeneration, plus the unbundled map delivery.
Nothing here is bundled or installed: it lies outside the Vite root (`frontend`), and the
app never reads it.

- `originals/pet-map-art` holds the lossless WebP originals of the AION 2 client map
  textures and overviews, under their original hash names.
- `delivery/pet-map-art` holds their delivery encodings, generated by
  `scripts/build-map-art.mjs`. They are not installed: the release packs them per map and
  the app downloads each map's pack the first time its art is shown.
- `originals/game-art`, `originals/pet-art` and `originals/resource-art` hold the verified
  original class and skill icons (lossless WebP, pixel-identical to NCSOFT's PNGs), pet
  portraits and resource icons (PNGs as served). The app ships their compact encodings in
  `frontend/public`, generated by `scripts/build-compact-art.mjs`.

`npm run check:art` requires each archived and delivered file to match its recorded
checksum. See [bundled AION 2 artwork](../docs/GAME_ARTWORK.md).
